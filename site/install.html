간호국 챗봇 설치 방법

간호국 챗봇은 설치 없이 웹에서 바로 사용할 수 있습니다. 자주 사용하는 경우 모바일 홈 화면 또는 PC 바탕화면에 추가해 앱처럼 빠르게 실행할 수 있습니다.

설치하지 않아도 웹에서 바로 사용 가능합니다.

Microsoft Edge

간호국 챗봇 주소창⊞⋯

주소창의 앱 아이콘 또는 오른쪽 위 메뉴

  1. 간호국 챗봇 웹사이트에 접속합니다.
  2. 주소창의 설치 아이콘 또는 오른쪽 위 ⋯ 메뉴를 선택합니다.
  3. 앱 → 이 사이트를 앱으로 설치 또는 간호국 챗봇 설치를 선택합니다.
  4. 설치 후 필요하면 바탕화면 / 시작 메뉴에 고정합니다.
  5. 간호국 챗봇 아이콘으로 실행합니다.

Google Chrome

간호국 챗봇 주소창↓⋮

주소창의 설치 아이콘 또는 오른쪽 위 메뉴

  1. 간호국 챗봇 웹사이트에 접속합니다.
  2. 주소창의 설치 아이콘 또는 오른쪽 위 ⋮ 메뉴를 선택합니다.
  3. 간호국 챗봇 설치를 선택합니다. 메뉴에서는 전송, 저장 및 공유 → 페이지를 앱으로 설치로 표시될 수 있습니다.
  4. 설치 후 바탕화면 / 시작 메뉴에서 실행합니다.

안드로이드 · Chrome

간호국 챗봇 주소창⋮

브라우저 오른쪽 위 메뉴

  1. Chrome에서 간호국 챗봇 웹사이트에 접속합니다.
  2. 오른쪽 위 ⋮ 메뉴를 선택합니다.
  3. 앱 설치 또는 홈 화면에 추가를 선택합니다. 설치 및 바로가기 만들기 → 설치로 표시될 수도 있습니다.
  4. 설치 버튼을 선택합니다.
  5. 홈 화면의 해백이 아이콘으로 실행합니다.

아이폰 · Safari

아이폰은 Safari에서 진행해주세요.

Safari 하단 도구 막대

위로 향한 화살표가 있는 공유 버튼

  1. Safari에서 간호국 챗봇 웹사이트에 접속합니다.
  2. 하단의 공유 버튼을 선택합니다. 안 보이면 더 보기 → 공유를 선택합니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 추가 버튼을 선택합니다. 웹 앱으로 열기가 표시되면 켜 둡니다.
  5. 홈 화면의 해백이 아이콘으로 실행합니다.

공용 PC에서는 로그인 상태 유지를 권장하지 않습니다.

메뉴 이름과 위치는 브라우저 버전에 따라 조금 다를 수 있습니다.
