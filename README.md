# 해백이 무료 GitHub Pages
직원은 게시된 PPT 검색 데이터와 원본 슬라이드 이미지를 자동으로 받아 사용합니다. 직원 파일 선택과 업로드 기능은 없습니다. 기존 디자인·동의어 검색·결과 선택·PWA를 유지합니다.

## 관리자 자료 등록 (한 번 게시하면 전체 사용자 반영)
1. 저장소 코드를 내려받고 tools/admin.html을 관리자 PC에서 엽니다.
2. 기존 자료가 있다면 이전 haebaek-publication.zip을 먼저 불러옵니다.
3. PPTX를 여러 개 선택하고 PowerPoint에서 PNG로 저장 → 모든 슬라이드를 선택합니다. 해당 PPT를 선택한 뒤 PNG들을 연결합니다. 같은 이름의 PPT는 교체되며 새 이미지도 연결해야 합니다. 자료 삭제도 가능합니다.
4. 모든 추출 원문과 원본 이미지를 직접 검토합니다. 개인정보·내부 정보가 없는지 확인하고 인터넷 공개 승인이 있는 자료에만 확인 체크합니다.
5. 게시용 ZIP을 만들고 PC에 보관합니다. 원본 PPT는 포함되지 않으며 검색 원문과 PNG만 포함됩니다.
6. ZIP 압축을 풀어 data 폴더로 저장소 site/data를 교체합니다. 기존 이미지도 삭제해야 하므로 로컬 Git 작업을 권장합니다. 관리자 GitHub 계정으로 commit/push하면 Actions가 자동 배포합니다.
7. 배포 완료 후 직원은 사이트에 접속하기만 하면 됩니다. 검색 데이터는 매번 새로 요청하고 이미지는 버전별 이름을 사용합니다.

PPT 등록은 웹사이트의 관리자 로그인이 아니라 GitHub 쓰기 권한으로 제한됩니다. 게시 자료는 인터넷에서 누구나 열람할 수 있습니다. 관리자 도구는 tools/에 있고 Pages의 site/ 배포에 포함되지 않습니다. 원본 Windows 프로그램과 DB는 변경하지 않습니다.

현재 실제 병원 자료의 공개 승인은 확인되지 않았으므로 slides.json은 비어 있습니다. 승인된 자료를 관리자가 위 과정으로 한 번 게시하면 전체 사용자에게 자동 제공됩니다. 자동 개인정보 탐지만으로 공개 승인 여부를 판단하지 마세요.
