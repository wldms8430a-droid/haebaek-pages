# 해백이 GitHub Pages
운영비 0원: 서버와 E5 없이 브라우저에서 한국어 동의어·약어, 제목과 핵심어 가중치로 여러 PPT를 통합 검색합니다. 답변은 추출 원문을 표시합니다.

## 자료 추가 / 교체
1. 사이트의 자료 관리에서 PPTX 여러 개를 선택합니다. 파일은 업로드되지 않습니다.
2. PowerPoint에서 PNG로 저장하고 모든 슬라이드를 선택합니다.
3. 자료 관리에서 해당 PPT를 선택하고 Slide1.png / 슬라이드1.png 등 원본 PNG들을 연결합니다.
4. 같은 파일명을 다시 선택하면 새 PPT로 교체됩니다. 새 이미지도 연결합니다.
5. 묶음 ZIP은 original.pptx, manifest.json(original_filename), slides/slide-1.png 등을 담으면 한 번에 연결됩니다.

자료는 탭 메모리에서만 사용합니다. 새로고침 후 다시 선택해야 하며 다른 직원 기기로 자동 배포되지 않습니다. 공개 승인 전 실제 병원 자료는 저장소에 올리지 않습니다. 자료 관리의 원문 검토와 원본 이미지 확인으로 개인정보·비공개 내용을 직접 점검하세요. 자동 탐지는 완전하지 않습니다.

기존 디자인, 원본 캐릭터, 확대 보기와 PWA를 유지합니다. 기존 Windows 프로그램과 DB는 변경하지 않습니다.
