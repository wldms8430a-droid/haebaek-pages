관리자용 공개 자료 준비

이 도구는 관리자 PC에서만 실행합니다. GitHub 쓰기 권한이 있는 관리자만 게시할 수 있습니다. 여기서 파일을 선택해도 외부로 전송되지 않습니다.

기존 자료를 유지하려면 이전에 만든 게시 ZIP부터 불러온 다음 추가·교체하세요.

PowerPoint에서 PNG로 저장 → 모든 슬라이드를 선택하세요.

공개 전 검토

모든 원문과 이미지를 확인하세요. 이름·사번·개인 연락처·내부 정보가 있으면 제외하세요. 아래 자동 탐지는 공개 가능 여부를 판정하지 않습니다.

다운로드 ZIP의 data 폴더로 저장소 site/data를 교체하고 commit하면 GitHub Actions가 모든 직원에게 자동 반영합니다. 원본 PPT 파일은 ZIP에 포함되지 않습니다.
